## ✨ Features

- **🎮 4 Unique Game Modes**:
  - **Marathon**: Endless classic play with speed scaling as you clear lines.
  - **40 Lines (Sprint)**: Clear 40 lines as fast as you can.
  - **Blitz**: Score maximum points before the 2-minute timer runs out.
  - **Zen**: Casual practice mode with auto-clearing rows when topping out.
- **⚡ Shop & Loadout System**:
  - Earn **Cores** by playing runs and clearing lines.
  - Unlock active abilities:
    - 💣 **Line Bomb**: Instantly clears your fullest row.
    - 🐌 **Slow-Mo**: Halves gravity for 8 seconds.
    - 💠 **Second Chance**: Auto-saves you once by clearing the stack if you top out.
    - ✨ **Score Surge**: Gives +50% score boost on your next run.
- **🕹️ Dual Control Modes**:
  - **Normal (Mouse Mode)**: Features an animated glowing neon custom cursor.
  - **Keyboard-Only Mode**: Complete menu navigation using arrow keys, space, enter, and escape—no mouse needed.
- **🎵 Chiptune Audio & Effects**:
  - Built-in Web Audio API synthesizer for background music and sound effects.
  - Dynamic music tempo that speeds up as game levels increase.
- **💎 Cyberpunk Visual FX**: Glow UI panels, line sweep animations, particle effects, screen shake, and pause overlays.

## 🎮 Controls

### In-Game Controls
| Action | Keyboard Key | Touch Button |
| :--- | :--- | :--- |
| Move Left / Right | `←` / `→` | `◀` / `▶` |
| Rotate Piece | `↑` | `⟳` |
| Soft Drop | `↓` | `▼ Soft` |
| Hard Drop | `Space` | `⤓ Drop` |
| Pause Game | `P` | Pause Button |
| Use Line Bomb | `Q` | Ability Slot |
| Use Slow-Mo | `E` | Ability Slot |

### Menu Controls (Keyboard-Only Mode)
| Action | Key |
| :--- | :--- |
| Move Selection | `Arrow Keys` |
| Select / Confirm | `Enter` / `Space` |
| Go Back / Cancel | `Esc` |

## 🛠️ Built With

- **HTML5 Canvas**: Frame-by-frame 2D matrix board rendering, ghost piece forecasting, and particle physics.
- **CSS3**: Custom properties, responsive flex/grid layouts, glassmorphism, and keyframe animations.
- **JavaScript (ES6+)**: Custom game engine, state management, local storage persistence, and dynamic event routing.
- **Web Audio API**: Real-time synthesized chiptune music and sound effects.
